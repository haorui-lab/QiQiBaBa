# What does "QiQiBaBa" mean?
**QiQiBaBa** (七七八八) is a vibrant Chinese idiom that literally translates to "sevens and eights," meaning "pretty much there" or "almost identical."

We named it this because when you use this prompt to reverse-engineer an AI image, the newly generated image will be "QiQiBaBa" (70-90% identical) to the original!
